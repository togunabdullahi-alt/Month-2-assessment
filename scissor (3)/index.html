FAQs

How does URL shortening work?

URL shortening works by taking a long URL and creating a shorter, condensed version that redirects to the original URL. When a user clicks on the shortened link, they are redirected to the intended destination.

Is it necessary to create an account to use the URL shortening service?

No. You can shorten links without an account, but signing up unlocks link analytics, custom slugs and branded domains.

Are the shortened links permanent? Will they expire?

Shortened links stay active for as long as your account does. Free plan links may be removed if they go unused for an extended period.

Are there any limitations on the number of URLs I can shorten?

The Basic plan lets you shorten unlimited URLs. Higher plans add extra features such as branded domains and team tools.

Can I customize the shortened URLs to reflect my brand or content?

Yes. Create custom slugs and, on paid plans, use your own branded domain so every link carries your identity.

Can I track the performance of my shortened URLs?

Every link comes with analytics showing clicks over time. Paid plans add deeper breakdowns of your audience.

How secure is the URL shortening service? Are the shortened links protected against spam or malicious activity?

All links are served over HTTPS and screened for spam and malicious destinations before and after they are created.

What is a QR code and what can it do?

A QR code is a scannable image that opens a link. Generate one for any shortened URL to bring customers to your business, event or page.

Is there an API available for integrating the URL shortening service into my own applications or websites?

Yes. The Teams plan includes API access so you can create and manage links from your own applications.
